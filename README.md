# AutoVideo Editor

An automated AI-assisted video editing pipeline built using Python and FFmpeg.

## Project Overview

This project automates several video editing tasks, including:

- Original audio replacement with custom voice-over
- Hinglish subtitle generation and rendering
- Video resizing and processing
- Background audio mixing
- Final MP4 video rendering

## Technologies Used

- Python
- FFmpeg
- Whisper / Faster-Whisper
- MoviePy (if used in the implementation)
- Kaggle Notebook
- Audio Processing

## Workflow

1. Load the source video and custom voice-over.
2. Process the audio and generate captions.
3. Render subtitles onto the video.
4. Mix voice-over and background audio.
5. Export the final edited video.

## Project Status

Initial working prototype. Further improvements are planned for scene detection, automatic sound selection, and editing quality.
